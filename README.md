## 🌟 Overview

Tanveer Tracker Pro v8.1 is a client-side powerhouse designed to handle daily business operations smoothly without requiring complex backend servers. It features local persistence via localStorage, real-time interactive charts, printable dynamic invoices and payslips, a drag-and-drop Kanban agile board, a CRM client directory, biometric attendance logging, and complete petty cash financial management.

---

## ✨ Core Features

* 📊 Real-Time Analytics Dashboard: Instant overview of pending tasks, total clients, generated invoices, net cash flow, and visual breakdown charts powered by Chart.js.
* 📋 Agile Kanban Board: Interactive drag-and-drop task management system categorized into To Do, In Progress, and Done with priority badges.
* 👥 CRM Client Directory: Complete client management system that syncs directly with the invoice generator for seamless billing.
* 📄 Smart Invoice Generator: Dynamic billing engine with automated calculations and a clean print view layout optimized for professional PDF generation and printing.
* 🖐️ Attendance & Biometric Log: Daily workforce tracking suite supporting statuses like Present, Late, Half-Day, and Absent.
* 💰 Enterprise Payroll Calculator: Automated payslip calculation factoring in basic salary, allowances, overtime hours/rates, and deductions.
* 📈 Petty Cash Ledger: Income and expense tracking with running totals and net balance calculations.
* 📥 Export & Backup Suite: One-click Excel workbook export (using SheetJS/XLSX) and complete JSON system backup capabilities.

---

## 🛠️ Tech Stack

* Frontend: HTML5, Tailwind CSS (v3 with Dark Mode support)
* Scripting: Vanilla JavaScript (ES6+)
* Icons & Fonts: FontAwesome 6, Google Fonts (Inter)
* Libraries: Chart.js, SheetJS (XLSX)

## 🚀 Getting Started & Usage

1. Clone the repository: git clone
2. ```https://github.com/vexornull/tanveer-tracker.git```
3. Open the project: Simply double-click index.html or run it via a live server extension in your preferred code editor (e.g., VS Code).
4. Data Persistence: All records (tasks, invoices, attendance, clients, and expenses) are securely stored locally inside your browser's localStorage.
